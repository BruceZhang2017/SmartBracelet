## 🎯 核心功能说明

### 新增功能

#### 1. 连接超时属性
```objc
// WPBluetoothManager.h
@property (nonatomic, assign) NSTimeInterval connectionTimeout;
```

**特性**：
- 默认值：30 秒
- 可自定义：建议 10-60 秒
- 设为 0 禁用（不推荐）

#### 2. 超时回调方法
```objc
// WPBluetoothManagerDelegate 协议
- (void)didConnectionTimeout:(WPPeripheralInfo *)peripheralInfo;
```

**触发时机**：
- 调用 `connectPeripheral:` 后
- 在 `connectionTimeout` 时间内未连接成功
- SDK 自动取消连接后回调

#### 3. 自动超时保护
- ✅ 扫描到设备但不在范围 → 30 秒后自动取消
- ✅ UUID 快速重连但设备关机 → 30 秒后自动取消
- ✅ 连接成功时自动取消定时器
- ✅ 连接失败时自动取消定时器

## 📖 使用指南

### 基础使用（默认配置）

```objc
// 1. 初始化（无需额外配置，默认 30 秒超时）
[[WPBluetoothManager sharedInstance] initCentral];
[WPBluetoothManager sharedInstance].delegate = self;

// 2. 实现超时回调
- (void)didConnectionTimeout:(WPPeripheralInfo *)peripheralInfo {
    NSString *deviceName = peripheralInfo.peripheral.name ?: @"未知设备";
    NSLog(@"⏰ 连接超时：%@", deviceName);

    // 提示用户设备不在范围内
    [self showAlert:@"设备不在范围内，请确保设备已开机并靠近手机"];
}
```

### 自定义超时时间

```objc
// 设置为 20 秒
[WPBluetoothManager sharedInstance].connectionTimeout = 20.0;

// 设置为 60 秒（长超时）
[WPBluetoothManager sharedInstance].connectionTimeout = 60.0;

// 禁用超时（不推荐）
[WPBluetoothManager sharedInstance].connectionTimeout = 0;
```

### 完整示例（来自 ExampleViewController.m）

```objc
- (void)viewDidLoad {
    [super viewDidLoad];

    // 初始化蓝牙管理器
    [[WPBluetoothManager sharedInstance] initCentral];
    [WPBluetoothManager sharedInstance].delegate = self;

    // 🆕 v2.0.6: 配置连接超时（可选）
    [WPBluetoothManager sharedInstance].connectionTimeout = 20.0;
}

// 🆕 v2.0.6: 连接超时回调
- (void)didConnectionTimeout:(WPPeripheralInfo *)peripheralInfo {
    dispatch_async(dispatch_get_main_queue(), ^{
        NSString *deviceName = peripheralInfo.peripheral.name ?: @"未知设备";
        NSString *mac = peripheralInfo.macAddress ?: @"";

        // 更新 UI
        self.statusLabel.text = [NSString stringWithFormat:@"⏰ 连接超时: %@ (%@)", deviceName, mac];

        // 提示用户
        UIAlertController *alert = [UIAlertController
            alertControllerWithTitle:@"连接超时"
            message:[NSString stringWithFormat:@"设备 %@ 不在范围内或无法连接。\n\n请确保：\n1. 设备已开机\n2. 设备在蓝牙范围内\n3. 设备未被其他应用连接", deviceName]
            preferredStyle:UIAlertControllerStyleAlert];
        [alert addAction:[UIAlertAction actionWithTitle:@"确定" style:UIAlertActionStyleDefault handler:nil]];
        [self presentViewController:alert animated:YES completion:nil];
    });
}
```
