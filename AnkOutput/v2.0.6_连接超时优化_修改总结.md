- (void)didConnectionTimeout:(WPPeripheralInfo *)peripheralInfo {
    dispatch_async(dispatch_get_main_queue(), ^{
        NSString *deviceName = peripheralInfo.peripheral.name ?: @"未知设备";
        NSString *mac = peripheralInfo.macAddress ?: @"";

        self.statusLabel.text = [NSString stringWithFormat:@"⏰ 连接超时: %@ (%@)", deviceName, mac];

        UIAlertController *alert = [UIAlertController alertControllerWithTitle:@"连接超时"
                                                                       message:[NSString stringWithFormat:@"设备 %@ 不在范围内或无法连接。\n\n请确保：\n1. 设备已开机\n2. 设备在蓝牙范围内（约10米内）\n3. 设备未被其他应用连接", deviceName]
                                                                preferredStyle:UIAlertControllerStyleAlert];
        [alert addAction:[UIAlertAction actionWithTitle:@"确定" style:UIAlertActionStyleDefault handler:nil]];
        [self presentViewController:alert animated:YES completion:nil];

## 🎯 核心实现逻辑

### 工作流程

```
开始连接
   ↓
调用 connectPeripheral:
   ↓
启动 connectionTimer（30秒）
   ↓
┌──────────────┬──────────────┐
│  连接成功    │  连接超时    │
│  ↓           │  ↓           │
│  取消定时器  │  取消连接    │
│  ↓           │  ↓           │
│  正常流程    │  回调应用层  │
└──────────────┴──────────────┘
```

### 超时触发时的处理

1. **取消系统连接**：`[centralManager cancelPeripheralConnection:peripheral]`
2. **清理内部状态**：从 `connectingPeripherals` 列表移除
3. **通知应用层**：调用 `didConnectionTimeout:` 代理方法
4. **清理定时器**：`invalidate` 并置 `nil`

### 保护机制

- ✅ 连接成功时自动取消定时器
- ✅ 连接失败时自动取消定时器
- ✅ 断开连接时自动取消定时器
- ✅ dealloc 时清理定时器，防止泄漏

## 📝 关键代码片段

### 启动超时定时器
```objc
- (void)startConnectionTimerForPeripheral:(CBPeripheral *)peripheral {
    [self.connectionTimer invalidate];
    self.connectingPeripheral = peripheral;

    if (self.connectionTimeout > 0) {
        self.connectionTimer = [NSTimer scheduledTimerWithTimeInterval:self.connectionTimeout
                                                                target:self
                                                              selector:@selector(connectionTimerFired:)
                                                              userInfo:nil
                                                               repeats:NO];
    }
}
```

### 超时触发处理
```objc
- (void)connectionTimerFired:(NSTimer *)timer {
    if (self.connectingPeripheral) {
        CBPeripheral *peripheral = self.connectingPeripheral;

        // 取消连接
        [self.centralManager cancelPeripheralConnection:peripheral];

        // 通知代理
        if ([self.delegate respondsToSelector:@selector(didConnectionTimeout:)]) {
            [self.delegate didConnectionTimeout:peripheralInfo];
        }

        [self cancelConnectionTimer];
    }
}
```

**原始问题**：
> 之前记录的手表不在扫描范围了，APP 没办法重连成功，就会一直连，不会停止

**解决方案**：
✅ 新增 `connectionTimeout` 属性（默认 30 秒）
✅ 新增 `didConnectionTimeout:` 代理方法
✅ 超时后自动取消连接并回调应用层

**预期效果**：
- 设备不在范围时，最多 30 秒后停止连接
- 应用层收到超时通知，可提示用户
- 完全向后兼容，现有应用无需修改
